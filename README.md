# Project 1: *Manuscript*

For this website, built around Yoon Soo Lee’s essay Judgment and Beauty and my response to it, I wanted to explore the idea of contrast, starting with the title, Design vs Judgment. I explored this contrast through typeface, color, and size.

For the typeface, I used a serif and a sans serif to create this contrast. “Design” is set in an italic serif typeface because it feels more decorative and expressive, while “Judgment” is set in a bold sans serif that feels heavy, direct, and blunt, reflecting the way judgment states things rather than decorating them.

For color, I was inspired by Jan van Toorn and Jean Leering’s The Debate, where each speaker is represented by a different color, red or blue. As highly contrasted colors, red and blue create a strong visual distinction between the two voices. The text also shifts across the page, with large margins separating each speaker. I used a similar approach, with blue appearing when the text discusses design and beauty, and red when it discusses judgment. I also used large margin shifts to separate the section titles from the body text, and used it for my response as well to seperate my response to design and my response to judgment.

Finally, the section headings are sticky, staying with the reader as they scroll through each section. This emphasizes the idea that judgment is always present throughout the design process, and in this case, throughout the website.
